# Wallpapers

The starter wallpapers are original pixel-art night cityscapes, drawn by
[`tools/gen_wallpapers.py`](../tools/gen_wallpapers.py) and released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Each one is drawn on a 320x200 grid and
enlarged 8x without smoothing (2560x1600). The script uses fixed seeds, so running it again reproduces
these files.

They exist so a fresh install has something to set and matugen has images to take colour from. Put your
own pictures in `~/Pictures/Wallpapers`; the installer only copies these when the folder has no file of
the same name, and never restores what you deleted.

| File | Mood |
|---|---|
| `City Midnight.png` | deep blue night, full moon |
| `City Neon.png` | violet sky, neon windows |
| `City Amber.png` | warm dusk glow, moon |
| `City Harbour.png` | blue night over water, reflections |
| `City Emerald.png` | teal sky, green-white windows |
| `City Dawn.png` | purple to orange horizon |
| `City Day.png` | light: blue day sky (for light mode) |

Earlier versions of this folder held 30 images taken from community HyDE themes. Their licences could not
be confirmed, so they were removed before the repository was made public.
